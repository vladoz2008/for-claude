# Три невозможные вещи

> «Иногда я успевала поверить в шесть невозможных вещей ещё до завтрака» — Белая Королева, «Алиса в Зазеркалье»

Одностраничное приложение с тремя живыми GPU-сценами: релятивистская чёрная дыра
«Гаргантюа», искусственная жизнь «Ления» и морфирующий 3D-фрактал «Мандельбульб».
Каждый кадр — чистая математика: ни одного изображения, ни одной сторонней
библиотеки, всё считается на лету в WebGL2-шейдерах. Страница открывается сразу
в чёрную дыру, во весь экран — сцена и есть главный герой, интерфейс лишь
сдержанно подписывает происходящее.

## Как открыть

Открыть `index.html` двойным щелчком — файл самодостаточен и работает прямо
с диска, без сборки и без сервера. Либо поднять локальный сервер:

```sh
npx serve .
```

## Управление

| Действие | Клавиша / жест |
| --- | --- |
| Переключить сцену | `1` / `2` / `3`, `←` / `→`, или клик по переключателю внизу справа |
| Скрыть / показать интерфейс | `H` |
| Во весь экран | `F` |
| Пауза (внутри сцены) | `Space` |
| Сброс камеры (внутри сцены) | `R` |
| Облёт / вращение / панорама | перетаскивание мышью или пальцем |
| Зум | колесо мыши или щипок двумя пальцами |

Ссылка вида `index.html#lenia` открывает страницу сразу на нужной сцене.

## Сцены

### I. Гаргантюа

Чёрная дыра в метрике Шварцшильда, названная в честь той самой «Гаргантюа» из
фильма «Интерстеллар». Сцена трассирует лучи света не по прямым, а по
геодезическим искривлённого пространства-времени: ускорение фотона в изотропных
координатах —

```
a = −1,5 · h² · x / |x|⁵
```

где `h` — сохраняющийся угловой момент луча. Горизонт событий задан радиусом
Шварцшильда `r_s = 1`, последняя устойчивая круговая орбита (ISCO) вещества в
диске — `3 r_s`. Цвет диска смещается доплеровским и гравитационным
красным/синим смещением в зависимости от скорости вещества и удалённости от
горизонта, отчего приближающийся край диска светится ярче и голубее, а
удаляющийся — тусклее и краснее.

### II. Ления

Continuous cellular automaton (Lenia) — обобщение «Игры "Жизнь"» на непрерывное
пространство, время и состояния клеток. На каждом шаге поле обновляется так:

```
A ← clip(A + Δt · G(K ∗ A))
```

где `K` — кольцевое ядро свёртки радиуса `R = 13`, а `G` — гауссова функция
роста с центром `μ = 0,15` и шириной `σ = 0,015`, решающая, растёт клетка,
умирает или остаётся неизменной в зависимости от «сытости» её окрестности.
Из этого простого правила рождаются устойчивые организмы: они дышат,
скользят и делятся, как настоящие одноклеточные.

### III. Мандельбульб

Трёхмерное обобщение множества Мандельброта: точка `c` принадлежит фракталу,
если последовательность

```
z ↦ zⁿ + c
```

в тройных (трипланарных) сферических координатах остаётся ограниченной.
Поверхность не хранится явно — она рисуется методом трассировки расстояний
(ray marching) по оценке дистанции

```
DE = ½ · ln r · r / dr
```

где `r = |z|`, а `dr` накапливает производную по итерациям. Каждый кадр камера
медленно облетает фрактал, а степень `n` плавно дышит, обнажая новые складки
поверхности.

## Архитектура

- **`src/scenes/*.js`** — три независимых модуля сцен. Каждый регистрирует
  себя в `window.SCENES[id]` и реализует единый контракт: `mount(host, ui)`
  создаёт canvas и WebGL2-контекст внутри `host`, добавляет до трёх кнопок
  управления в `ui`, сама владеет вводом (указатель, колесо, `Space`/`R`) и
  возвращает `{ unmount() }`, полностью освобождающий ресурсы GPU. Разрешение
  канваса адаптивно подстраивается под частоту кадров.
- **`src/shell/`** — оболочка: `template.html` (вёрстка с плейсхолдерами
  `{{STYLE}}`/`{{SCRIPTS}}`), `shell.css` (единственная тёмная тема, все цвета
  — через переменные) и `shell.js` (монтирует/размонтирует сцены, переключатель,
  клавиатура, полноэкранный режим, скрытие интерфейса, deep-link по `#hash`).
- **`build.mjs`** — без зависимостей, на чистом Node.js, склеивает шаблон,
  стили, три сцены (в порядке `gargantua → lenia → mandelbulb`) и `shell.js`
  в два файла:
  - `index.html` — полный документ, открывается прямо с диска;
  - `dist/artifact.html` — тот же интерфейс единым фрагментом (без
    `doctype/html/head/body`) для встраивания в Claude Artifacts.

  ```sh
  node build.mjs                      # index.html, dist/artifact.html
  node build.mjs --out-dir=some/dir   # собрать в другую папку
  SCENES_DIR=dev/stubs node build.mjs # собрать с тестовыми заглушками
  ```

- **`dev/`** — независимые песочницы для разработки каждой сцены
  (`dev/<id>.html`) и оболочки (`dev/shell.html` + `dev/stubs/*.js` —
  заглушки сцен для проверки вёрстки до готовности настоящих сцен).

Никаких изображений, никаких библиотек — каждый пиксель вычислен.
